# Exemple : Classe avec des constantes

Cet exemple illustre la création d'une classe simple avec :

- Des propriétés privées pour l'encapsulation.
- Un constructeur pour initialiser l'objet.
- Une méthode `greet` qui retourne un message de salutation basé sur les
  propriétés de l'objet.
- Des constantes de classe pour définir des valeurs fixes et partagées entre
  toutes les instances de la classe.
